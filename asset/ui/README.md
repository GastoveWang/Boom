# Taiwan overview

`taiwan_natural_earth.geojson` contains the TWN feature from Natural Earth's
1:10m country geometry, downloaded on 2026-09-14. Natural Earth data is public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries.geojson

Used only as an offline geographic overview, not for localization. The locator
box represents the main viewport bounds; a minimum visible box is used when the
bounds would be smaller than a few pixels at national scale.
