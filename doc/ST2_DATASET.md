# ST² 區段與逐幀框選

這個工具為 Boom 新模型保存「有物體的時間區段」與「每一幀的關注區域 BBox」，不需要標記物體類別。可以先畫一個模板，將相同位置的框套用到所選區段，再逐幀微調；每幀仍分開保存。

時間軌顯示已標註區段、有框／缺框影格及目前播放位置，可直接點擊或拖曳跳轉。區段列表顯示開始／結束影格的秒數，滑鼠移到時間軌也會顯示精確秒數與影格範圍。

原版 ASTT 的資料與工具繼續留在 `benchmark/ASTT/`。本工具新輸出統一使用 `st2`；原 data/astt_bbox 已搬至 data/st2，output/astt_bbox 已搬至 output/st2，原資料與標註內容保留，舊 schema 繼續支援。

## 啟動

從 Boom 根目錄、已具備 OpenCV、NumPy、Pillow 與 Tkinter 的環境執行：

```powershell
conda activate boom
python src/st2 prepare
```

繼續既有標註：

```powershell
python src/st2 prepare --project "output/st2/annotations/你的專案.json"
```

標註 UI 不需要載入模型或 PyTorch，也不會重新訓練。標註邏輯位於 `src/st2/data/annotations.py`，UI 位於 `src/st2/data/editor.py`。

## 標註流程

1. 按「加入影片」；也支援直接包含連續圖片的資料夾，加入時輸入圖片序列的實際 FPS。
2. 設定「原始來源群組」。同一影片的不同片段、解析度版本及其抽幀序列應使用相同群組名稱。群組與標註一起按「儲存」保存。
3. 移到有物體區段的開始影格，按「設起點 S」；移到最後一幀，按「設終點 E」，再按「加入有物體區段」。影格編號從 1 開始，兩端都包含。
4. 在區段內一個具代表性的影格畫好模板。空白處（含框內）拖曳新增框；移到任何既有框的四角，游標變成斜向縮放箭頭，可直接拖曳調整形狀；移到邊線，游標變成四向箭頭，可平移整個框。不需先點選框；同一幀支援多個框。Ctrl＋拖曳或「畫新框」可強制新增重疊框。
5. 按「套用目前框到區段」。目前幀的所有框會以相同相對位置複製到起訖之間尚未有框的影格，保留既有框並略過 ignore 影格。套用框和手動畫的框直接使用同一種標註，不設待檢查／已檢查狀態；此操作可撤銷。套用不會追蹤物體移動，也不做插值。
6. 用時間軌或前後一幀逐幀微調；「下一缺框幀」或 N 只跳到區段內尚未有框的影格，不要求逐幀確認。
7. 無法判斷的影格可按「略過目前影格」，也能選擇起訖後「略過此區段」。略過優先於有物體區段，這些影格不作為正常負樣本，包含略過影格的歷史窗口也不匯出。
8. 按「儲存 Ctrl＋S」保存專案。上方路徑與視窗標題會提示有無未儲存修改。標註、來源增刪與群組修改不會自行寫入檔案。
9. 至少加入兩個獨立來源群組，按「預覽分組」，再按「產生資料集」。區段內仍缺框時不能匯出；區段外依工具規則視為無目標，無法判斷的畫面請明確略過。不需完成來源檢查或確認框。匯出會先保存專案，建立新版本，不覆寫先前版本或原始來源。

在區段外畫框會將目前影格加入有物體區段，避免已畫的框被靜默當成正常。刪除有物體區段會刪除其中不再屬於其他有物體區段的框，可用「撤銷上次修改」恢復。

時間軌上排：紅色為有物體區段，灰色為略過。下排：綠色為有框，淺紅色為缺框；藍線為目前播放位置，S／E 標示目前選定的起訖。影像上黃色只表示選取或滑鼠指向的框。細區段以影格所占的時間格顯示，文字秒數對應起訖影格本身的時間。

| 操作 | 快捷鍵／滑鼠 |
|---|---|
| 前／後一幀 | ←／→ |
| 前／後一秒 | Shift＋←／→ |
| 播放／暫停 | 空白鍵 |
| 設區段起點／終點 | S／E |
| 下一缺框幀 | N |
| 刪除選取框 | Delete |
| 撤銷修改 | Ctrl＋Z；保留目前來源最近 10 次框／區段修改 |
| 儲存專案 | 「儲存 Ctrl＋S」或 Ctrl＋S |
| 縮放／平移 | 滾輪／中鍵拖曳 |

有未儲存修改時，關閉視窗、建立新專案或載入其他專案會被攔住；提示中按「是」先儲存再繼續，按「否」留在目前專案。儲存失敗也會留在頁面，不提供丟棄修改直接關閉。滑鼠仍在拖曳時需先放開，才能儲存或關閉。沒有變更時可直接關閉；只瀏覽、播放、縮放或改選時間範圍不算標註修改。

「另存專案」要求新檔名；儲存只能更新同一個標註專案 ID，不會覆寫其他專案或任意 JSON。載入時檢查原始來源的檔案列表、大小及修改時間，來源被修改時需重新加入。

新專案格式為 `st2.annotations.v1`，不保存框或來源的檢查狀態。既有 boom.astt_bbox.v1／v2／v3 專案仍可載入，忽略舊的 `reviewed`／`pending_frames`；保存時使用 st2.annotations.v1，原有區段與框座標保留。

## 路徑

```text
Boom/
├── data/st2/prepared/<名稱>_vN/
│   ├── project.json                # 本次標註快照
│   ├── split_report.json           # 群組分配、窗口與略過統計
│   ├── README.md
│   ├── train/<來源名稱_ID>/
│   │   ├── images/                 # 完整歷史畫面，保留原尺寸
│   │   ├── frames.jsonl            # 每幀狀態、原尺寸及手動 ROI 框
│   │   ├── samples.jsonl           # 可用的歷史窗口及最後影格 targets
│   │   ├── labels.npy              # 1=有框區段、0=無目標、-1=略過
│   │   ├── frames.csv              # 原幀號、時間與檔名對應
│   │   └── source.json             # 原始來源、群組與 FPS
│   └── val/<來源名稱_ID>/          # 相同格式
└── output/st2/
    ├── annotations/               # 手動儲存的標註專案
    ├── training/                  # ST² 訓練 run 與權重
    └── results/                   # checkpoint 獨立驗證結果
```

預設名稱 `st2`，匯出時選擇尚未存在的版本。首次為 `st2_v1`，已有 `st2_v1` 時會建立 `st2_v2`。UI 可選其他輸出父目錄及名稱。標註工具不產生訓練模型；目前資料集為 data/st2/prepared/st2_v1，新訓練資料以 --data 指定匯出位置。

## 時間、座標與分組

影片使用原始影格序列與原始固定幀率，不補幀或降採樣；時間為原幀號／來源 FPS。圖片依檔名自然排序，FPS 由使用者提供。可變幀率影片的真實 PTS 尚未支援，需先準備固定幀率來源。

框以相對原圖的 xyxy [0,1] 保存，縮放及平移只影響畫面顯示。影片匯出為原尺寸 JPEG（品質 95），原檔保留；圖片來源直接複製。`frames.jsonl` 中每幀有原始 width／height，`samples.jsonl` 的 target.boxes 為模型需要的相對 cxcywh。

`samples.jsonl` 使用包含目前幀的連續歷史窗口，預設 4 幀。頭 3 幀仍保存標註與畫面，但不產生完整窗口。窗口不跨來源，不跨略過影格；圖片檔名若有連續數字編號，缺號也會阻止跨缺幀窗口。剪接需拆成不同來源，工具不會自動偵測剪接。

預設按群組數近似分 train／val 7:3，seed 2026；所有同群組來源留在同一組，不隨機拆相鄰影格。這不是按影格數精確 7:3，也不建立獨立 test。切分要求 train 有可用的有框窗口，val 至少有可用窗口；val 沒有有框窗口時會提示無法評估目標召回／AP。

## 給模型的區域資料

`roi_xyxy` 是使用者的關注區域，可由框聯集建立注意力監督 mask。這些框未必是物體的緊密外框，不能當成已辨識物體類別或像素級分割真值。

為與現有單類框監督介面相容，samples 的 target.labels 固定為 0，表示單一關注區域；UI 不要求物體類別。匯出要求區段內非略過影格都有框；手動框與套用框均參與監督，不設確認門檻。

UI 與資料匯出供 [ST² 訓練](ST2.md) 使用：框聯集轉為 mask，訓練平衡 BCE／Dice；正常窗口訓練預測 MSE，背景運動分支以歷史 mask 排除配準中的目標區域。不使用舊直接框回歸 loss。匯出完成不代表模型已經學會關注目標；既有匯出資料夾中的 README 是歷史快照，訓練支援狀態以目前方法文件為準。

## 命令列預覽與匯出

```powershell
python src/st2 prepare --project "output/st2/annotations/你的專案.json" --preview
python src/st2 prepare --project "output/st2/annotations/你的專案.json" --export --output-parent data/st2/prepared --name st2 --ratios 7 3 --history-frames 4
```

取消或匯出失敗會清除本次獨佔建立的未完成版本；已存在的資料、原始影片及已完成版本都保留。
